# Сравнительный анализ Comb Sort и Quicksort

Курсовая работа по дисциплине «Алгоритмы и структуры данных».
ИжГТУ имени М.Т. Калашникова, 2025.

## Описание

Программа реализует два алгоритма сортировки на C++:
- Comb Sort — усовершенствованная сортировка пузырьком с зазором 1.247.
- Quicksort — быстрая сортировка по схеме Хоара со средним опорным элементом.

Оба алгоритма возвращают количество операций сравнения.

## Сборка и запуск

g++ -O2 -std=c++17 -o sort_experiment kyrsovaa.cpp
./sort_experiment

Или в Visual Studio 2026: открыть `kyrsovaa.slnx`, собрать в Release (/O2), запустить.

## Результаты

Программа тестирует массивы размеров 100, 500, 1000, 2000, 5000, 10000, 20000, 50000.
Для каждого размера генерируется 10 000 случайных наборов данных.
Средние значения сохраняются в `results.csv`.
